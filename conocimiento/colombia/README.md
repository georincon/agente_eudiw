# Conocimiento verificado de Colombia — convención de estados

| Estado | Significado | Uso |
|---|---|---|
| **VERIFICADO** | Leído en el texto oficial íntegro (PDF/Diario Oficial/certificado/sentencia) | Se puede citar |
| **VERIFICADO-RA** | Leído en una copia pública oficial o normograma pero con **resumen automático** (herramienta WebFetch); suele conservar citas breves fiables, no el texto íntegro | Citar con la marca "RA"; **releer el texto íntegro antes de usarlo en un documento jurídico** |
| **SECUNDARIO** | Prensa, firmas de abogados, agregadores | No condiciona decisiones |
| **NO VERIFICADO** | Sin lectura | No entra aquí; va al backlog (PLAN-MAESTRO §7) |
