# Diccionario bilingüe UE → Colombia

> Glosario del ecosistema. Propósito: fijar el término en inglés del estándar + la equivalencia
> o adaptación local que usamos en el proyecto, para que siempre hablemos el mismo idioma.

| Término UE | Siglas | Adaptación CO / nota |
|---|---|---|
| European Digital Identity Wallet | EUDI Wallet | Billetera/Identidad Digital Nacional (concepto de referentem, se adapta a la estrategia MinTIC) |
| Person Identification Data | PID | Credencial de identidad nacional (equivalente: cédula digital) |
| Electronic Attestation of Attributes | EAA | Certificado/credential de atributos |
| Qualified EAA | QEAA | (n/d en Colombia por el momento: requiere régimen de cualificación) |
| PuB-EAA (attestation by public body) | PuB-EAA | Credencial emitida por entidad pública desde una fuente auténtica |
| Wallet Unit | — | Unidad de wallet (app instalada + elemento seguro) |
| Wallet Provider | — | Operador de la wallet (Estado u operador certificado) |
| Relying Party | RP / WRP | Verificador / parte confiable (banco, entidad, tienda) |
| Access Certificate Authority | Access CA | Autoridad certificadora de acceso |
| Provider of Registration Certificates | — | Emisor de certificados de registro (ámbito) |
| Registrar | — | Registrador del ecosistema (posible RNEC o autoridad designada) |
| Trusted List / List of Trusted Entities | TL / LoTE | Lista de entidades de confianza (análogo nacional) |
| Conformity Assessment Body | CAB | Evaluador de conformidad (posible esquema vía ONAC) |
| Supervisory Body | — | Autoridad supervisora (posible SIC para datos/firma) |
| Level of Assurance | LoA | Nivel de aseguramiento (alto/substancial/bajo) |
| OpenID4VCI | — | Protocolo de emisión de credenciales |
| OpenID4VP | — | Protocolo de presentación de credenciales |
| SD-JWT | — | Formato de credencial con divulgación selectiva |
| mDL / ISO 18013-5 | — | Licencia de conducción móvil (muy útil para Mintransporte/SIMIT) |
| Selective Disclosure | — | Divulgación selectiva (compartir solo el dato necesario) |
| Device binding / User binding | — | Vinculación a dispositivo / a la persona titular |
| Key Attestation | KA | Atestación de claves (emitida por el Wallet Provider) |
| Wallet Instance Attestation | WIA | Atestación de la instancia de wallet |
| Functional Conformance Assessment Framework | FCAF | Marco de evaluación funcional (casos de prueba de conformidad) |
| Authentic Source | — | Fuente auténtica (registro oficial que origina el dato) |
| Wallet-Relying Party | WRP | Verificador registrado (CIR 2025/848) |
